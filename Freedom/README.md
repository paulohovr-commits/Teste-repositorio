# Freedom

Uma IA que funciona como **agência de marketing automatizada**, gerenciando 100% da operação da agência.

## Fase atual: Caderno de Desabafos

Durante 1 a 2 semanas, cada ideia de recurso é despejada livremente (como desabafo) e eu anoto tudo aqui.
Nada é construído ainda. O objetivo é descobrir a visão do todo.

Para cada desabafo, o registro contém:
1. **O que foi dito** (fiel, sem inventar)
2. **O recurso entendido**
3. **Cruzamentos**: o que ele ganha ao se conectar com outros recursos (a "inteligência" do sistema)
4. **Integrações** necessárias
5. **Alertas de segurança**
6. **Perguntas em aberto**

## Arquivos

| Arquivo | Para quê |
|---|---|
| `desabafos/` | Um arquivo por desabafo, em ordem cronológica |
| `recursos.md` | Índice de todos os recursos já mencionados |
| `cruzamentos.md` | Mapa de inteligência: o que se conecta com o quê |
| `integracoes.md` | Lista consolidada de integrações externas |
| `seguranca.md` | Lista consolidada de alertas de segurança |
| `perguntas-em-aberto.md` | Dúvidas para decidir depois |
